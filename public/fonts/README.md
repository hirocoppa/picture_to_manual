# Japanese PDF font

Source: Google Fonts / Noto Sans JP
https://github.com/google/fonts/tree/main/ofl/notosansjp

NotoSansJP-Regular.ttf is a static weight-400 instance of NotoSansJP[wght].ttf, generated with fontTools.varLib.instancer. It is embedded as a subset in generated PDFs. The SIL Open Font License is included in LICENSE.txt. The reserved name "Source" is not used as the font name.
